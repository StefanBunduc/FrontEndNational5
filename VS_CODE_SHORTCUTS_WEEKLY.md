# VS Code — două shortcuturi pe săptămână

Tracker personal, separat de temele de frontend. Sursa: [PDF-ul oficial VS Code pentru Windows](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf) (verificat: 7 septembrie 2026).

## Cum înveți

Folosește cele două comenzi de cel puțin cinci ori într-o temă reală, apoi bifează rândul și completează data. Pentru secvențe precum `Ctrl+K`, `Ctrl+C`, apeși prima combinație, o eliberezi, apoi pe a doua.

**Cheie de memorie:** `Ctrl` = control/comandă; `Shift` schimbă sensul sau extinde; `Alt` mută ori oferă o variantă alternativă. Nu este o regulă perfectă, dar e un bun punct de plecare.

| 6 | ☐ `Ctrl+Shift+K` — șterge linia | ☐ `Ctrl+Enter` — linie dedesubt | **K = kill; Enter = rând nou.** Ștergi CSS greșit și scrii imediat sub linia curentă. | |

| 10 | ☐ `Ctrl+↑/↓` — derulează o linie | ☐ `Alt+PgUp/PgDn` — derulează o pagină | **Muți „camera”, nu cursorul.** Citești codul din jur fără să-ți pierzi poziția. | |

| 28 | ☐ `Shift+Alt+→` — extinde selecția | ☐ `Shift+Alt+←` — micșorează | **Dreapta = mai mult.** Crești selecția de la cuvânt la expresie și element HTML. | |
| 29 | ☐ `Shift+Alt` + drag — coloană | ☐ `Ctrl+Shift+Alt` + săgeți — coloană | **Ca o coloană Excel.** Selectezi doar valorile CSS după `:` pe mai multe rânduri. | |

| 32 | ☐ `Ctrl+K`, `Ctrl+F` — formatează selecția | ☐ `F12` — definiția | **F = format/find definition.** Aranjezi doar codul lipit; intri în funcția importată. | |
| 33 | ☐ `Alt+F12` — Peek Definition | ☐ `Ctrl+K`, `F12` — definiția alături | **Alt privește fără plecare.** Verifici o funcție în pop-up; o deschizi lateral pentru comparație. | |

| 35 | ☐ `F2` — Rename Symbol | ☐ `Ctrl+K`, `Ctrl+X` — șterge spații finale | **F2 redenumește sigur.** Schimbi `userName` peste tot, apoi cureți spațiile invizibile. | |
| 36 | ☐ `Ctrl+K`, `M` — limbaj fișier | ☐ `Ctrl+F4/Ctrl+W` — închide fila | **M = Mode, W = close.** Un fișier fără extensie devine HTML; închizi apoi fila. | |

| 38 | ☐ `Ctrl+1/2/3` — focus grup | ☐ `Ctrl+K`, `Ctrl+←/→` — grup vecin | **Numărul spune unde mergi.** Ajungi în panoul 2; cu săgeți mergi pas cu pas. | |
| 39 | ☐ `Ctrl+Shift+PgUp/PgDn` — mută fila | ☐ `Ctrl+K`, `←/→` — mută grupul | **Page mută „pagina”.** Reordonezi CSS lângă HTML sau muți întreg panoul. | |

| 43 | ☐ `Ctrl+K`, `Ctrl+W` — închide toate | ☐ `Ctrl+Shift+T` — redeschide | **T = take it back.** Ai închis prea mult? ca în Chrome, readuci fila. | |
